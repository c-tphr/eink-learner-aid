# Real books

Real public-domain books prepared end to end with `/prep-book` (docs/PLAN.md section 8, "Test material"). Unlike the synthetic fixture described in `README.md`, these files are not generated: they are the source as downloaded and the outputs of a recorded `/prep-book` run. This file is maintained by hand, because `README.md` is generated by `tools/prep/fixture/generate.py` and must stay byte-identical to its output.

## *Essays* by Thomas Paine (Standard Ebooks)

The Standard Ebooks collection *Essays*: *Common Sense* (its first and longest essay, 19,335 words), The Republican Proclamation, Anti-Monarchal Essay, Declaration of Rights, Dissertation on First Principles of Government, The Decline and Fall of the English System of Finance and Agrarian Justice. Standard Ebooks has no stand-alone *Common Sense*, so the whole collection was prepared. Prepared in issue #38 (task P5); the run is documented in `docs/evidence/p5/README.md`.

| File | What it is |
| --- | --- |
| `paine-essays.epub` | The original EPUB from Standard Ebooks, unmodified. SHA-256 `96d9e4c1356048ed87bc5ebd2dcbcfa21db28e5679de16f70d35ebaac6529561`, 420,162 bytes |
| `paine-essays.LICENSE.md` | Where and when it was downloaded, and its public-domain dedication quoted from the file |
| `paine-essays.draft.json` | The final draft (round 2): sections, exclusions, checkpoints and prompts with their cited paragraphs. Rebuild the prepared book from it with `prep build`; a later re-preparation must keep its ids |
| `paine-essays.prepared.epub` | The prepared book exactly as `prep report` delivered it (READY). SHA-256 `c9afc99966c698b85c7755670264daaf2b32e1f331c932092bb02887ea23ca50` |
| `paine-essays.validation-report.md`, `.json` | The report from `prep report`: READY, 2 rounds, every check and every issue raised |

Rebuild and check:

```sh
python3 -m tools.prep build fixtures/books/paine-essays.epub fixtures/books/paine-essays.draft.json -o /tmp/paine-essays.prepared.epub
cmp /tmp/paine-essays.prepared.epub fixtures/books/paine-essays.prepared.epub   # identical bytes
python3 -m tools.prep validate fixtures/books/paine-essays.epub fixtures/books/paine-essays.prepared.epub --draft fixtures/books/paine-essays.draft.json
python3 -m tools.prep report --original fixtures/books/paine-essays.epub --prepared fixtures/books/paine-essays.prepared.epub --history docs/evidence/p5 -o /tmp/paine-report
```
